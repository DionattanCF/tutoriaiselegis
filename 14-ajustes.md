# Módulo Ajustes — Configuração do gabinete

O módulo de Ajustes é onde o administrador do gabinete configura o sistema: cria e gerencia usuários, define permissões de acesso, organiza setores e ajusta notificações automáticas. É a área mais estratégica do sistema — mudanças aqui afetam todos os membros da equipe.

---

## Para que serve o módulo de Ajustes

Os Ajustes controlam como o sistema funciona para o seu gabinete. É aqui que você:
- Adiciona novos usuários e define o que cada um pode fazer
- Cria setores para organizar as demandas
- Configura notificações e agendamentos automáticos
- Ajusta as configurações gerais da conta

---

## Usuários

Gerenciar usuários é a tarefa mais importante dos Ajustes. Cada pessoa que precisa acessar o Elegis deve ter um usuário cadastrado com as permissões adequadas.

**Como adicionar um novo usuário:**
1. Acesse **Ajustes → Usuários** e clique em **Adicionar**.
2. Informe se o usuário está vinculado a um cadastro já existente na base. Se sim, busque pelo nome. Se não, preencha os dados manualmente.
3. Preencha: nome, e-mail e celular para notificações WhatsApp (obrigatório).
4. Se houver setor, informe (não obrigatório).
5. Na seção de permissões, defina o que o usuário pode fazer em cada módulo.

**Como funciona a matriz de permissões:**

Para cada módulo você pode conceder permissão de Ver, Criar, Editar e Excluir de forma independente. Por exemplo, uma recepcionista pode ter permissão de Ver e Criar demandas, mas não de Excluir.

Dois módulos têm um tipo de permissão especial chamado **Restrito**:

- **Cadastro Restrito**: o usuário só vê os cadastros que ele mesmo inseriu no sistema. Se tiver 5 cadastros feitos por ele, vê apenas esses 5. Ideal para lideranças com acesso ao sistema que não devem ver os cadastros uns dos outros.

- **Demandas Restrito**: o usuário só vê as demandas em que é o destino do último andamento — ou seja, as demandas que foram encaminhadas diretamente para ele. Garante que cada pessoa foque apenas nos processos de sua responsabilidade.

---

## Setores

Setores organizam as demandas por área de atuação. Exemplos: Saúde, Infraestrutura, Habitação, Assessoria Jurídica.

Como criar um setor:
1. Acesse **Ajustes → Setores** e clique em **Adicionar**.
2. Dê um nome claro ao setor.
3. Salve.

Os setores aparecem nos filtros de demandas e relatórios. Mantenha os nomes estáveis para que as comparações entre períodos façam sentido.

---

## Configurações gerais

Em **Ajustes → Configurações** você encontra as definições gerais da conta: identidade do gabinete, integrações ativas e outros parâmetros da plataforma.

Tenha cuidado ao alterar as configurações gerais — mudanças nessa área afetam imediatamente toda a equipe.

---

## Agendamentos

Em **Agendamentos** você configura notificações automáticas e lembretes ligados ao sistema. Por exemplo, a notificação diária da agenda (enviada todo dia pela manhã com os compromissos do dia) é configurada aqui.

Não confunda com o módulo de Agenda, que é para cadastrar eventos e compromissos. Os Agendamentos em Ajustes são para configurar comportamentos automáticos do sistema.

## Perguntas e Respostas

**Quem pode acessar o módulo de Ajustes?**
Apenas usuários com permissão de administrador ou papel equivalente. Usuários comuns não veem o menu de Ajustes.

**Como dou acesso a um novo colaborador do gabinete?**
Acesse Ajustes → Usuários, clique em Adicionar e preencha os dados. Defina as permissões conforme a função que a pessoa vai desempenhar. O sistema enviará o acesso para o e-mail informado.

**O que acontece se eu der permissão de Excluir para todos os usuários?**
Qualquer usuário poderá excluir registros no módulo correspondente. Isso aumenta o risco de perda de dados. Recomendamos dar permissão de Excluir apenas para usuários confiáveis e responsáveis pela administração.

**Posso mudar as permissões de um usuário depois de criado?**
Sim. Abra o cadastro do usuário em Ajustes → Usuários, edite e ajuste as permissões. A mudança entra em vigor na próxima vez que ele acessar o sistema ou recarregar a página.

**O que é o papel Master?**
O Master é o nível mais alto de acesso no sistema. Usuários Master têm acesso a todas as funcionalidades, incluindo assinaturas, cobranças e troca de equipe. Atribua esse papel com cuidado.

**Como crio setores para organizar as demandas?**
Acesse Ajustes → Setores e clique em Adicionar. Dê um nome ao setor e salve. Os setores aparecem nas demandas para que a equipe possa classificar cada atendimento por área.

**Posso excluir um usuário que saiu da equipe?**
Sim. Abra o cadastro do usuário em Ajustes → Usuários e use a opção de desativar ou excluir. Desativar é mais seguro pois mantém o histórico de ações do usuário no sistema.

**Por que um usuário não consegue ver um módulo mesmo sendo do gabinete?**
Verifique a matriz de permissões do usuário em Ajustes → Usuários. Se o campo "Ver" de um módulo não estiver marcado, o usuário não terá acesso àquele menu.
