# Tutoriais do Elegis — Guia completo do sistema

O Elegis é um sistema de gestão de gabinete parlamentar que centraliza em um único lugar tudo o que o mandato precisa: cadastro de eleitores e apoiadores, atendimento de demandas, comunicação por WhatsApp e e-mail, documentos, agenda, relatórios e muito mais.

Esta documentação é um guia prático escrito para a equipe do gabinete. Cada arquivo corresponde a um módulo do sistema e contém explicações claras, passo a passo e perguntas frequentes com respostas.

---

## Como o sistema está organizado

O Elegis tem um menu lateral com todos os módulos agrupados. A navegação é simples: clique no grupo e depois no item que deseja acessar. Se não encontrar um módulo, use a barra de pesquisa do menu — basta digitar o nome da funcionalidade.

Cada usuário vê apenas os módulos para os quais tem permissão. Se um item não aparece no menu, provavelmente é uma questão de permissão — fale com o administrador do gabinete.

## Por onde começar

Se você é novo no Elegis, recomendamos a seguinte ordem de aprendizado:

1. Leia o tutorial do **Painel** para entender a tela inicial
2. Estude o módulo de **Cadastro** — é a base de tudo no sistema
3. Aprenda **Demandas** para registrar e acompanhar os pedidos da população
4. Explore os módulos de comunicação: **WhatsApp**, **SMS** e **E-mail**
5. Configure **Ajustes** com a ajuda do administrador antes de começar a operar

---

## Dicas gerais de uso

- O sistema trabalha com dados da equipe selecionada. Se você tem acesso a mais de uma conta, certifique-se de estar na equipe correta antes de começar.
- Sempre clique em **Sair** ao terminar de usar — nunca feche apenas o navegador.
- Em caso de dúvida, use a barra de busca do menu para encontrar qualquer funcionalidade.
- Mantenha a base de cadastros atualizada — ela é a base de todos os outros módulos.
