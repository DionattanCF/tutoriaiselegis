# Módulo Demandas — Atendimento e protocolos

O módulo de Demandas é onde o gabinete registra, acompanha e resolve os pedidos da população. Cada solicitação vira um protocolo com número único, responsável definido e histórico de tudo que foi feito. Nada se perde e o trabalho do mandato fica documentado.

---

## Para que serve o módulo de Demandas

Toda vez que um eleitor traz um pedido — uma consulta médica, uma obra no bairro, um documento, um encaminhamento — esse pedido deve virar uma demanda no sistema. Isso garante que:

- A solicitação tenha um número de protocolo para rastrear
- A equipe saiba quem é o responsável por resolver
- O histórico de cada andamento fique registrado
- Você possa provar o trabalho realizado com relatórios

---

## Como criar uma nova demanda

1. Clique em **Demandas** no menu lateral e depois em **Nova Demanda**.
2. Selecione o **Assunto** da demanda (saúde, infraestrutura, habitação etc.). Os assuntos são cadastrados pelo administrador e ajudam a categorizar e gerar relatórios.
3. Vincule a demanda a um **Cadastro** — procure o nome da pessoa que fez o pedido. Isso conecta a demanda ao histórico daquele eleitor.
4. Preencha o texto com o detalhamento do pedido.
5. Salve. O sistema gera um número de protocolo automaticamente.

---

## Andamentos

Os andamentos são o histórico de tudo que aconteceu com uma demanda: quem recebeu, o que foi feito, para onde foi encaminhada.

Para registrar um andamento:
1. Abra a demanda.
2. Localize a seção de **Andamentos**.
3. Escreva o texto do andamento (o que foi feito, para quem foi encaminhado, qual a situação).
4. Defina o **usuário destino** — a pessoa responsável pelo próximo passo.
5. Salve.

Cada andamento fica registrado com data, hora e nome de quem fez. Isso cria uma trilha de auditoria completa.

---

## Assuntos

Os assuntos são as categorias das demandas. Exemplos comuns: Saúde, Educação, Infraestrutura, Habitação, Emprego, Documentação.

Para gerenciar os assuntos, o administrador acessa **Demandas → Assuntos** e pode criar, editar ou desativar categorias. Manter os assuntos organizados é fundamental para que os relatórios façam sentido.

Se um assunto for marcado como **Externo**, ele aparece nos formulários de atendimento compartilhados com a população.

---

## Visibilidade restrita

O sistema tem uma configuração de **acesso restrito** para demandas. Quando um usuário tem acesso restrito, ele só consegue ver as demandas em que é o destino do último andamento — ou seja, as demandas que foram encaminhadas diretamente para ele.

Isso é muito útil quando lideranças ou atendentes de campo têm acesso ao sistema mas não devem ver os processos uns dos outros.

Um usuário **sem** acesso restrito (como o gestor do gabinete) vê todas as demandas.

---

## Como usar demandas junto com formulários

Você pode criar um formulário de **Demanda** e compartilhar o link com lideranças ou publicar em redes sociais. Quando alguém preenche o formulário, a demanda já entra automaticamente no sistema vinculada à pessoa que compartilhou o link.

Isso permite que uma liderança colete pedidos em campo sem precisar acessar o sistema — ela só compartilha o link e os atendimentos chegam organizados.

---

## Perguntas e Respostas

**Por que só consigo ver algumas demandas e não todas?**
Seu usuário provavelmente tem configuração de acesso restrito. Nesse modo, você vê apenas as demandas cujo último andamento foi encaminhado para você. Se precisar ver mais, peça ao administrador para revisar suas permissões.

**Posso vincular uma demanda a uma pessoa que não está cadastrada?**
Tecnicamente é possível criar uma demanda sem vincular a um cadastro, mas o recomendado é sempre vincular. Isso garante que o histórico da pessoa fique completo e que você possa gerar relatórios por eleitor.

**O que acontece quando encaminho uma demanda para outro usuário?**
O usuário que receber o encaminhamento passa a ser o destino do último andamento. Se ele tiver acesso restrito, a demanda vai aparecer para ele. Você continua podendo ver a demanda se não tiver acesso restrito.

**Como sei se uma demanda foi resolvida?**
O sistema não tem um status automático de "resolvido" — isso é definido pela equipe em cada andamento. O padrão é registrar um andamento final descrevendo a resolução. Alguns gabinetes criam categorias de andamento como "Concluído" ou "Arquivado" para padronizar.

**Posso criar uma demanda a partir de um formulário preenchido pela população?**
Sim. Crie um formulário do tipo **Demanda**, compartilhe o link e as solicitações chegam automaticamente no sistema. Se ativar a opção de "Aprovar Lead", elas ficam em espera para revisão antes de entrar na lista de demandas.

**Como gero um relatório das demandas por assunto?**
Vá em **Relatórios → Relatório de Demandas** e aplique os filtros de assunto, período, setor ou usuário. Você pode exportar o resultado em planilha.

**Posso excluir uma demanda?**
Sim, se você tiver permissão de exclusão. Mas o recomendado é manter o histórico completo e, se necessário, arquivar por andamento em vez de excluir.

**Como funciona a ligação entre Demandas e Documentos?**
Ao criar um ofício ou documento, você pode vincular a uma demanda. Isso facilita o rastreamento: a demanda fica com o documento associado e o documento fica com o protocolo da demanda.
