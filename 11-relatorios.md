# Módulo Relatórios — Análises e dados do gabinete

O módulo de Relatórios transforma os dados do Elegis em informações úteis para a gestão do mandato. Você acompanha o volume de demandas, o desempenho dos atendimentos, o ranking de indicações e até dados eleitorais — tudo em tela, com filtros e opção de exportar para planilha.

---

## Para que serve o módulo de Relatórios

Os relatórios respondem perguntas como:
- Quantas demandas foram abertas no último mês?
- Quais os assuntos mais solicitados?
- Quem são os maiores indicadores da minha base?
- Como estão os atendimentos por setor?
- Onde estão geograficamente os meus votos?

Essas informações ajudam na tomada de decisão, no planejamento de campanhas e na prestação de contas do mandato.

---

## Relatório de Demandas

O Relatório de Demandas mostra todas as solicitações registradas com opções de filtro por assunto, período, setor, usuário responsável e cadastro.

Como usar:
1. Acesse **Relatórios → Relatório de Demandas**.
2. Aplique os filtros desejados (data de abertura, assunto, setor, status).
3. Analise os dados na tela ou clique em **Exportar** para baixar uma planilha.

Esse relatório é essencial para comprovar o trabalho do mandato e identificar quais áreas geram mais demanda da população.

---

## Relatório de Atendimentos

Focado nos atendimentos registrados na Central de Atendimento, este relatório mostra o volume e o desempenho por período.

Como usar:
1. Acesse **Relatórios → Relatório de Atendimentos**.
2. Selecione o período que deseja analisar.
3. Visualize os gráficos ou tabelas com o volume de atendimentos.

---

## Ranking de Indicações

Mostra quem são as pessoas da base que mais fizeram indicações — ou seja, quem trouxe mais contatos para o banco de dados.

Como usar:
1. Acesse **Relatórios → Ranking de Indicações**.
2. Veja a lista dos maiores indicadores com a quantidade de indicações de cada um.
3. Exporte para planilha se precisar compartilhar ou analisar externamente.

Esse ranking é muito útil para reconhecer e valorizar as lideranças mais ativas.

---

## Dados de Eleições e Mapa do Voto

O sistema pode exibir dados eleitorais e um mapa de votação geográfico, permitindo cruzar informações de onde estão os votos com onde estão os cadastros da base.

Como usar:
1. Acesse **Relatórios → Dados Eleições** ou **Mapa do Voto**.
2. Selecione a eleição, o estado, o município ou outros filtros disponíveis.
3. Visualize os resultados no mapa ou em tabela.

Essa informação estratégica ajuda a identificar regiões fortes e territórios onde ainda é possível crescer.

Se esse item não aparecer no menu ou apresentar erro de acesso, pode ser uma questão de permissão de usuário. Solicite acesso ao administrador.

## Perguntas e Respostas

**O relatório de demandas mostra dados de toda a equipe ou só os meus?**
Por padrão, o relatório mostra os dados de toda a equipe. Se seu usuário tiver acesso restrito, pode exibir apenas as demandas vinculadas a você.

**Posso exportar qualquer relatório para Excel?**
A maioria dos relatórios tem botão de exportação. Onde disponível, o arquivo é gerado em formato de planilha (Excel ou CSV). Verifique se o botão aparece na tela de cada relatório.

**Por que o relatório está lento para carregar?**
Relatórios com períodos longos ou muitos dados podem demorar. Experimente filtrar por um período menor, como um mês específico, para agilizar o carregamento.

**O Mapa do Voto usa os dados de qual eleição?**
Depende de quais dados eleitorais foram carregados no sistema. Geralmente os dados correspondem à última eleição disponível na base. Consulte o suporte para saber quais eleições estão disponíveis.

**Como identifico se o volume de demandas está crescendo ou caindo?**
No Relatório de Demandas, filtre por meses consecutivos e compare os totais. Você também pode ver os gráficos de evolução mensal no Painel (Home) do sistema.

**O Ranking de Indicações inclui apenas indicações feitas pelo formulário externo?**
O ranking considera todas as indicações registradas no sistema, tanto as feitas pelo formulário externo quanto as inseridas manualmente nos cadastros.

**Posso criar relatórios personalizados?**
O módulo de Relatórios oferece filtros pré-configurados. Para análises mais avançadas e personalizadas, exporte os dados para Excel e faça a análise na planilha.

**Os dados eleitorais são atualizados automaticamente após cada eleição?**
Não. Os dados eleitorais precisam ser carregados manualmente no sistema. Entre em contato com o suporte para solicitar atualização após uma nova eleição.
